WEBNICSS — ПРОВЕРКИ

Все файлы этой версии лежат в одной папке. Тестовые скрипты не размещайте в публичном веб-корне. Требуются Node.js 18+, Python, Playwright 1.47.2 и установленный браузер Chromium. Для проверки сначала запустите локальный сервер в этой папке:
  python3 -m http.server 8080 --bind 127.0.0.1
В Windows вместо python3 можно использовать py. В другом терминале запустите:
  node integration-prep.js
  node release-check.js
  node navigation.js
Playwright можно установить отдельно и указать Node путь к нему через NODE_PATH, чтобы не создавать служебный node_modules внутри папки сайта. Некоторые Linux-системы требуют системных библиотек Chromium. Тесты не проверяют реальные платежи, WordPress, юридическое соответствие или безопасность сторонних сервисов.
