# WEBNICSS — файлы в одной папке

Обновлено 30 октября 2026 года. В этой версии **все файлы сайта, изображения, шрифты и инструкции находятся в одной папке**, без вложенных каталогов. Откройте `НАЧНИТЕ-ЗДЕСЬ.txt` для краткого порядка действий.

## Основные файлы

- `index.html`, `projects.html`, `shop.html`, `product.html`, `service.html` — страницы сайта.
- `privacy.html`, `terms.html`, `security.html` — проекты политики, условий заказа и сведений о безопасности. Перед запуском проверьте и утвердите их под фактические процессы.
- `main.js`, `bootstrap.js`, `styles.css`, `legal.css`, `core3d.js`, `fonts.css` и локальные файлы шрифтов — оформление и логика; 3D-фигура вращается мышью и пальцем. Часы на странице проектов загружаются из `watch3d.bundle.js`; исходные файлы сцены — `watch3d.js`, `OrbitControls.js` и `three.module.js`.
- Картинки товаров начинаются с `product-`, команды — с `team-`, работ — с `work-`. Другие локальные изображения и библиотеки лежат здесь же.
- `INSTRUCTIONS.md`, `INTEGRATION-PLAN.md`, `SECURITY-LAUNCH.md`, `woocommerce-products-draft.csv` — инструкции и девять товаров-черновиков WooCommerce. `integration-prep.js`, `release-check.js` и `navigation.js` — проверки, сведения в `TESTS-README.txt`.
- `.htaccess` — дополнительные заголовки и ограничения для Apache 2.4; файл скрытый. На Nginx и Python он не действует.

## Важное о запуске

Это редактируемая статическая витрина, **не тема WordPress и не подключённый магазин**. Хостинг, WordPress/WooCommerce, оплата и автовыдача пока не подключены. Локальная корзина не передаётся в бот и не создаёт реальный заказ. Цены услуг — предложения для согласования, четыре позиции без подтверждённого прайса показаны по запросу.

Для просмотра можно открыть `index.html` прямо из папки: переходы и 3D проверены в Chromium. Если браузер ограничивает локальные скрипты, запустите в этой папке `python3 -m http.server 8080 --bind 127.0.0.1` (в Windows — `py -m http.server 8080 --bind 127.0.0.1`) и перейдите на `http://localhost:8080/`. После изменения исходного `watch3d.js`, `OrbitControls.js` или `three.module.js` пересоберите используемый страницей файл командой `npx --yes esbuild@0.25.5 watch3d.js --bundle --format=iife --target=es2020 --legal-comments=inline --outfile=watch3d.bundle.js` (нужны Node.js и доступ к npm).

Хотя все файлы в архиве собраны в одну папку, **инструкции, `*.txt`, `*.md`, CSV и тестовые `integration-prep.js`, `release-check.js`, `navigation.js` нельзя публиковать в веб-корне**: оставьте их у себя и загружайте на сервер только файлы сайта. `.htaccess` дополнительно ограничивает доступ к ним только на Apache; для Nginx/другого сервера защита настраивается отдельно. До запуска настройте HTTPS, резервные копии, доступы и проверьте политику данных/условия продажи.

Robokassa выбрана для заявки, но магазин не одобрен и не подключён. При проверке её модуля 1.9.0 обнаружены вопросы сверки суммы и обработки повторных уведомлений: до реальных платежей и автовыдачи устраните и перепроверьте их (см. `INSTRUCTIONS.md`). Не отправляйте никому пароли, токены и коды подтверждения.
